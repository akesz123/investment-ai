# AI Investment Assistant

An AI-powered investment research assistant that scans US stocks and ETFs, ranks opportunities for the next 30 days, and provides explainable, probability-based recommendations.

## Features
- Market scanner for 1000+ symbols
- Technical analysis
- Fundamental analysis
- News sentiment analysis
- Analyst ratings
- Macro analysis
- AI ranking engine
- ML predictions
- Portfolio module
- FastAPI REST API
- Streamlit dashboard
- Dockerized deployment

## Disclaimer
This application provides probability-based analysis only. It does not guarantee returns and must not be used as financial advice.
